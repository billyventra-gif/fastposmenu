## Part B — How menus get in, per POS

### 1. Heartland Restaurant / Genius for Restaurants (Global Payments)
Heartland Restaurant (HRPOS) has a Back-Office **Import/Export tool** that works with a spreadsheet, normally one you exported first. Under the Genius rebrand it lives at Admin Portal → Tools → Import/Export → **Menu** tab. It is an export-edit-reimport workflow rather than a documented blank template.
- **Ingestion:** XLSX import/export tool (self-serve). Heartland's menu API (`api.hrpos.heartland.us/v2/menu/...`, covering items, sections, groups, sizes, tags and modifier options) is **partner/certified only**.
- **Structure:** Groups → Sections → Menu Items → Modifiers → Ingredients. Each item has one kitchen group, one reporting category and one section, plus optional sizes and multiple modifiers ([Heartland menu guide](https://heartlandpos.zendesk.com/hc/en-us/article_attachments/27100736695067)).
- **Gotchas:** The 2019 guide says to import Items separately (they are the slowest) and in batches of ≤200 ([Import/Export Tool Guide PDF](https://pos.heartlandpaymentsystems.com/kb/kb_upload/file/Import_Export%20Tool%20Guide.pdf)). The account's language configuration must match exactly between export and import ([Genius Menu Translations](https://help.globalpayments.com/genius/restaurant-point-of-sale/online-ordering/menu-translations-user-guide)). Admin Portal 9.133 fixed a bug where ingredient records in full-menu files did not import ([release notes](https://help.globalpayments.com/genius/restaurant-point-of-sale/release-notes/genius-admin-portal/genius-admin-release-notes-9133)). Deliverect reports the API cannot configure "context items" or required ingredients ([Deliverect](https://help.deliverect.com/en/articles/7979164-heartland-features-and-limitations)).
- **Third-party push:** API keys come from the developer portal, and production keys are issued only after Heartland certification ([Supergood summary](https://supergood.ai/api-report-card/heartland-restaurant)). VERIFY whether the menu endpoints allow writes.
- **UNDOCUMENTED:** Exact sheet names and column headers. **A sample export from a real account is needed.**

### 2. SpotOn Restaurant
Back of House (BOH) has a **Menu Import** with a downloadable CSV "Menu Item Template" (Menu → Menu Import → upload .CSV). Separately, the Menu Items **Bulk Editor** exports and imports a narrow CSV (Item, Location, Available, Standard Price) for price and availability edits only.
- **Ingestion:** CSV template import (self-serve) plus the Bulk Editor CSV. API menu access is **read only**.
- **Fields:** Item Tax Percentage is accepted as a number or with a "%" sign ([Menu Item Import](https://spotonteam.atlassian.net/wiki/x/hoA6yw)). The Bulk Editor CSV has Item, Location, Available and Standard Price, and "is not a complete menu export" ([Bulk Editor](https://help.spoton.com/space/SK/881066143/Menu+Items+Bulk+Editor+%7C+SpotOn+Restaurant+BOH); [Download bulk info](https://help.spoton.com/space/SK/2658041895/Download+Menu+Item+Bulk+Information+|+SpotOn+Restaurant+BOH)).
- **Gotchas:** Modifier and modifier-group import is not confirmed (it is likely built manually or by onboarding). Commas can break columns if the spreadsheet locale treats separators differently.
- **Third-party push:** The Central API (CAP) offers Menus READ, Orders WRITE and Menu-update webhooks. There is **no documented menu write**. Access requires the integration intake form and Preferred Integration Partner selection, with no guarantee ([developers.spoton.com/central-api](https://developers.spoton.com/central-api/docs); [Menu Items API](https://developers.spoton.com/restaurant/docs/menu-items)).
- **UNDOCUMENTED:** Full template headers. **Download the "Menu Item Template" from a BOH account.**

### 3. Lightspeed Restaurant (K-Series)
This is the best-documented self-serve option of the group. Back Office has **item import/export** (CSV/XLSX) and **menu import/export**. Menu import can create a new menu, replace one, or do a test run. Combos have their own import.
- **Ingestion:** CSV/XLSX template with column mapping (self-serve). The public REST API is partner-approved.
- **Fields:** Mandatory columns are **Type** (Item / Sub-item / Group / Combo, with Modifier and Modifier Group values in the menu file), **SKU**, **Accounting group** and **Name**. Optional columns include **Price**. Groups require **Min - Max**. Modifiers use **Group name**, **Option name** and **Price adjustment**. Screens are addressed as `Menu/Screen/Sub-screen`. Combos link to items through **Parent SKU** ([Items import](https://k-series-support.lightspeedhq.com/hc/en-us/articles/1260804656109-Importing-and-exporting-items-in-bulk); [Menus import](https://k-series-support.lightspeedhq.com/hc/en-us/articles/1260804605430-Importing-and-exporting-menus); [Combos](https://k-series-support.lightspeedhq.com/hc/en-us/articles/4407631132827-Importing-and-exporting-combos)).
- **Gotchas:** Items assigned to accounting groups that don't exist fail unless the "create accounting groups" toggle is on. SKU and Type must be mapped. Unused columns must be set to "Skip for import". Tax comes through the accounting group, not a tax column. Sources disagree on whether Name is mandatory, so treat it as required.
- **Third-party push:** The K-Series API (`api-docs.lsk.lightspeed.app`) includes Items/"rich items" create, update and delete by SKU, plus menu load. Partners apply, are approved by Partner Services and get OAuth credentials ([Lightspeed Custom API Access PDF](https://files.cdn.thinkific.com/file_uploads/966438/attachments/a5a/a77/1d9/Custom_API_Access.pdf)). VERIFY the endpoint names on the official docs.
- **Documented:** Yes. A reference export is still recommended to lock column order.

### 4. Revel (Shift4)
Management Console has **Excel import/export** for products, modifiers, product-modifier links and recipes. You export a template and must keep all columns and headers exactly as they are.
- **Ingestion:** XLSX templates (self-serve). Revel has a **REST API** with `POST /resources/Product/` and a sandbox at `api-sandbox-revel.revelup.com`.
- **Fields:** Modifiers: Column A is Modifier Class Name, and each modifier needs a Barcode **or** SKU. The Basic export covers name, price, cost and active. The Advanced export adds color, kitchen print name and printers ([Modifier import](https://support.revelsystems.com/hc/en-us/articles/360016230391-Modifier-Import-Export)). Product-Modifier link file: one row per product-modifier pair with Product Name, Product Barcode, Product SKU and Modifier Class Name ([Product modifiers](https://support.revelsystems.com/s/article/How-to-Import-Export-Product-Modifiers-Using-Excel-1583154976207)). Products use Class, Category and Subcategory ([Recipes import](https://support.revelsystems.com/hc/en-us/articles/360020822151-How-to-Import-Recipes-Through-Import-Export); [Product import](https://support.revelsystems.com/hc/en-us/articles/203812719-Uploading-Your-Products-Using-Excel-Retail-)).
- **Gotchas:** Imports are **ordered**: create products and modifiers first, then link them. Newly imported modifiers are *not* attached to products. Any renamed or deleted column causes the import to be rejected. Revel 2.79 added `is_alcohol` to Product.
- **Third-party push:** The API exists ([developer.revelsystems.com](https://developer.revelsystems.com)). Keys are issued per establishment by Revel and require a partner agreement. VERIFY how auth keys are issued and whether Shift4 ownership changed the program.
- **UNDOCUMENTED:** Full restaurant product-sheet headers. **Export from a Management Console.**

### 5. TouchBistro
Cloud Admin / Remote Menu Management (RMM) has a **CSV bulk upload** for menu items only.
- **Ingestion:** CSV template (self-serve) for items only. There is no public API.
- **Fields:** Name, Short Name, UPC, Price, Menu Category Name. The category must already exist and the name must match exactly. A blank or out-of-range value falls back to the category default ([Bulk upload (RMM)](https://cdn.touchbistro.com/help/articles/bulk-uploading-new-menu-items/); [MM 1.0](https://www.touchbistro.com/help-articles/bulk-uploading-new-menu-items/)).
- **Gotchas:** ≤**200 items per upload**. No updating existing items, no image, **no tax setting**, no batch delete. **Modifier groups must be built manually** after the upload ([Modifiers](https://cdn.touchbistro.com/help/articles/working-menu-modifiers/)). Don't add columns.
- **Third-party push:** The API is partner-only. Apply via integratedpartners@touchbistro.com, sign an NDA and API agreement, and receive manually issued keys under commercial terms ([apis.io](https://apis.io/providers/touchbistro/); [NDA form](https://docs.google.com/forms/d/e/1FAIpQLSf1iexjegPvWh-ehsE3cm5dPPn0VrIShF_-WS2rpiP-7cXmvA/viewform)).
- **Partially documented:** Download the current template from Cloud Admin to confirm headers.

### 6. NCR Voyix Aloha
There are two worlds. **Aloha Cloud** (SMB) has a self-serve CSV **Item Import** with separate templates for items, variations and modifiers. **Aloha POS / Configuration Center** (enterprise, on-prem or hybrid) has no public spreadsheet import, and menus are built by NCR or a reseller.
- **Ingestion:** Aloha Cloud: CSV templates under Back Office → Settings & Privacy → Admin → Item Import, or Menu → Categories & Items ([Item Import](https://docs.ncrvoyix.com/restaurant/aloha-cloud/implementing/settings/admin_settings/working_with_item_import); [Managing menu](https://docs.ncrvoyix.com/restaurant/aloha-cloud/implementing/menu_management/managing_your_menu)). Enterprise Aloha: support- or reseller-assisted, or the BSP API.
- **Fields:** Mandatory fields are shown in red in the downloaded template, which includes sample rows. Back Office validates rows and marks errors with a red icon. Separate variation and modifier templates have their own error logs.
- **Gotchas:** **Only 5 modifier options per item via import**, even though the UI allows unlimited. Aloha Online Ordering uses a separate Menu Configurator that NCR seeds.
- **Third-party push:** NCR Voyix Business Services Platform (api.ncr.com, HMAC AccessKey auth) offers a Catalog API (`PUT /catalog/items`, `/catalog/item-prices`) and a Menu API. It requires the NCR partner program, per-integration certification and per-location fees ([apis.io Catalog](https://apis.io/apis/aloha-pos/aloha-pos-catalog-api/); [Supergood](https://supergood.ai/api-report-card/aloha-ncr)). On-prem sites rely on Aloha Connect or SQL. VERIFY that the BSP catalog writes reach the POS menu and not only digital ordering.
- **UNDOCUMENTED:** Column headers are not public. **Download a template from an Aloha Cloud account.**

### 7. Shift4 SkyTab (Shift4 Dine)
The menu build is **support-assisted**. Merchants submit their menu to Shift4's programming team using the **"POS Menu Import Template File"** or accepted competitor exports (e.g. Clover inventory export), or file a "SkyTab POS Menu Programming Request" form. Lighthouse has no documented self-serve spreadsheet import. Menu Manager's "Import from POS" only copies the POS menu into online ordering.
- **Ingestion:** Template submitted to support. Partner API through the Shift4 Marketplace.
- **Fields:** Prices are required on all items **and modifiers**. Menus must be final, with no placeholders ([Menu Submission Guide](https://shift4.zendesk.com/hc/en-us/articles/28528184692627-SkyTab-Menu-Submission-Guide); [2024 guide](https://shift4phoenix.my.site.com/shift4knowledge/s/article/000001731)). Agents can change at most about 10 items per engagement, and larger changes go through the form.
- **Gotchas:** Turnaround depends on the Shift4 programming queue. Online ordering's "Import from POS" is disabled once the site is already in sync ([Menu Manager import](https://shift4.zendesk.com/hc/en-us/articles/7816596215699-Import-Items-to-SkyTab-Menu-Manager-From-Your-POS)).
- **Third-party push:** The Marketplace API (`conecto-api.shift4payments.com`, OAuth 2.0 merchant authorization, JSON, HMAC webhooks) gives read/write access to SkyTab data. The merchant installs the partner app in Lighthouse → Marketplace and clicks Allow. Partners such as Maple *read* menus. **I found no confirmed menu-write endpoint** ([Marketplace API docs (unofficial mirror)](https://shift4-dev-portal.vercel.app/marketplace)). Partner onboarding goes through the Shift4 Marketplace partner team.
- **UNDOCUMENTED:** The template's columns. **Get the "POS Menu Import Template File" from Shift4 support or a merchant.**

## Takeaways for Fast POS Menu
- **Self-serve file targets now:** Lightspeed K (best documented), Revel (multi-file, ordered), Aloha Cloud (CSV, 5-modifier cap), TouchBistro (items only, ≤200), SpotOn (BOH template), Heartland/Genius (export-edit-import XLSX).
- **SkyTab:** Produce a filled "POS Menu Import Template" for Shift4's programming team. This is a strong pitch because it saves merchants a long support round-trip.
- **API push:** Every vendor here requires partner approval. Only Lightspeed K, Revel and NCR BSP clearly expose item-create endpoints. SpotOn and SkyTab appear read-only for menus.
- **Needs real sample exports:** Heartland/Genius, SpotOn, Revel (restaurant product sheet), Aloha Cloud, SkyTab template, and TouchBistro (current template).
