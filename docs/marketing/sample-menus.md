# Sample menus for demos, videos and screenshots

All restaurants and items are invented. Use these for every demo. Never use a real merchant's menu.

Print each on one letter page (two for Riverbend), in a plain restaurant style (serif heading, dotted leaders), and shoot it on a counter under warm light. Each includes the hard parts on purpose: sizes, required choices, priced add-ons, a market price, and a smudge or handwritten special to show the review flag.

## Shooting checklist

- Phone in portrait, screen recording on, Do Not Disturb on, notifications off.
- Hide the browser URL bar or use the installed web app so the vercel.app address isn't on screen.
- Show the flagged item being fixed in every video; it's the trust moment.
- End on the "READY" badge and the download, not on a spreadsheet.
- No real POS dashboards or logos on screen.
